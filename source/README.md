# Source Corpus

This directory is the controlled intake boundary for publication-safe material that may be used to construct the book.

Examples may include:

- published *What the Map Misses* essays;
- unpublished drafts intentionally released into this public project;
- selected MKS specifications approved for public use;
- publication-safe concept exports;
- prior public talks or essays;
- other authored material intentionally admitted to the corpus.

Because this repository is public, nothing should be placed here merely because it exists in a private workspace.

The first book loop will inventory the admitted corpus before extracting the thesis. Absence from this directory is not evidence that an idea does not exist; it means the idea has not yet been admitted to the public book-production corpus.
